# emulebb-rust Docs

The canonical emulebb-rust product, backlog, design, release, history, and API
docs live in:

`EMULEBB_WORKSPACE_ROOT\repos\emulebb-tooling\docs\products\emulebb-rust`

Keep this repo-local directory as a pointer only. Source code and crate-level
comments stay in this repository; maintained Markdown belongs in the tooling
docs tree.

Repo-specific build and download guidance remains in the root README. In
particular, see [Nightly beta builds](../README.md#nightly-beta-builds) for the
automated prerelease channel, generated changelogs, package links, container
tags, and retention policy. Each published nightly also carries its generated
release notes on the GitHub Releases page; those notes are build output rather
than a separately maintained document.
